# 🤖 Парсер сайта EORA с ИИ-ответами

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Telegram Bot](https://img.shields.io/badge/Telegram-Bot-blue.svg)](https://core.telegram.org/bots)

## 🎯 Цель проекта

Создать сервис, который:
1. Парсит сайт EORA.
2. Использует API LLM (например, DeepSeek через OpenRouter) для генерации ответов.

---

## 🚀 Возможности

- ✅ **Парсинг сайта**: Асинхронный парсинг страниц сайта.
- ✅ **ИИ-ответы**: Интеграция с LLM для генерации осмысленных и структурированных ответов.
- ✅ **Кликабельные ссылки**: Метки `[1]`, `[2]` в ответе бота являются гиперссылками на источники информации.

---

## 🧰 Используемые технологии

- **Python 3.11+**
- **Aiogram 3.x** - для создания Telegram-бота.
- **Aiohttp** - для асинхронных HTTP-запросов.
- **BeautifulSoup 4** - для парсинга HTML.
- **OpenAI Python API** - для взаимодействия с LLM через OpenRouter.
- **Asyncio** - для асинхронного выполнения задач.

## 🛠 Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ваш_логин/AI-Parses-Eora.git
    cd AI-Parses-Eora
    ```
2.  **Установите Poetry (если еще не установлен):**
    Следуйте официальной инструкции: [https://python-poetry.org/docs/#installation](https://python-poetry.org/docs/#installation)

3.  **Установите зависимости проекта с помощью Poetry:**
    ```bash
    poetry install
    ```

4.  **Активируйте виртуальное окружение Poetry:**
    ```bash
    poetry shell
    ```

5.  **Создайте файл `.env` на основе шаблона `.env.template` и заполните его своими данными:**
    ```bash
    cp .env.template .env
    # Откройте .env в текстовом редакторе и введите токены
    ```

6.  **Запустите бота:**
    ```bash
    python main.py
    ```

- Создал асинхронного Telegram-бота.
- Реализовал парсинг сайта EORA с помощью `aiohttp` и `BeautifulSoup`.
- Интегрировал ИИ (LLM) через OpenRouter.
- Настроил генерацию ответов с метками источников `[1]`, `[2]`.
- Реализовал прикрепление файлов `.txt` с содержимым страниц.

## ✅ Что сработало

- Парсинг сайта, форматирование и передача данных в ИИ.
- Генерация ответов ИИ с корректными метками.
- Форматирование ответа ИИ для меток-гиперссылок в Telegram.

---

## ❌ Что не сработало / с чем были трудности

- ИИ иногда выдавал метки в виде списков `[1, 2, 3]` вместо отдельных `[1] [2] [3]`. Решил путём уточнения инструкции.
- ИИ иногда пытался вывести список всех ссылок в конце сообщения. Решил путём уточнения инструкции и постобработки.
- Первоначально гиперссылки не работали из-за проблем с регулярными выражениями. Решил путём отладки и использования `aiogram.utils.markdown.hlink`.

---

## 📊 Как оценивали качество решения

- Проверял, соответствуют ли ответы информации с сайта.
- Убеждался, что метки, например `[1]`, `[2]` кликабельны и ведут на правильные страницы.
